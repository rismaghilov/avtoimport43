АВТОИМПОРТ43 — сайт v13 / 13.11.2026

Публикация: загрузите ZIP через Netlify Drop либо разместите все файлы в корне сайта. Сохраните папку assets и файлы tariffs.js/calculator.js рядом с index.html.

Обновления калькулятора:
- tariffs.js — единые ставки, коммерческие ставки, акциз 2026, НДС 22%, таможенные сборы и таблицы утилизационного сбора 2026/2027.
- calculator.js — собственный код расчёта без стороннего платного API; курсы валют ЦБ подгружаются через cbr-xml-daily.ru.
- 100 000 ₽ за брокера уже включены в сумму, доставка и услуги компании — отдельно.
- Сроки, договор и условия льготного утильсбора должны подтверждаться специалистом; входные данные не содержат VIN, дату выпуска/декларирования, страну происхождения и режим оформления, поэтому расчёт предварительный.
- Таблицы нуждаются в регулярной сверке с действующими нормативами до публикации и после изменения законодательства.
- Расчёт электромобилей и гибридов не предусмотрен по решению заказчика.
- Применение расчетов для юрлица/ИП может зависеть от тарифного кода ТН ВЭД, происхождения авто и особенностей оформления; расчёт ориентировочный.

Источники для проверки:
ПП РФ № 1291, № 1713; ПП РФ № 1637 и № 1638; Решение ЕЭК № 107; НК РФ ст. 193; ФНС по НДС 2026.

Проверено: синтаксис JS; браузерные сценарии для 3–5 лет, повышенного утильсбора, юрлица и отправки заявки. Реальный внешний сервис курсов и все законодательные случаи не проверены.

V17: обновлены только фоны первого экрана для компьютера (1.png) и телефона (2.png). Остальные файлы v16 без изменений.
